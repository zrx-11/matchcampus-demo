# 校配 MatchCampus · Demo

校园供需智能匹配平台 · 产品演示网站

## 快速开始

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 页面结构

```
校配_demo/
├── index.html          # 首页（产品介绍+数据+功能+商业模式）
├── match.html          # 匹配演示（学生端核心交互）
├── merchant.html       # 商家端（情报中心仪表盘）
├── about.html          # 关于（团队+发展路线）
├── assets/
│   ├── css/
│   │   └── style.css   # 全局样式
│   ├── js/
│   │   ├── data.js     # 预置数据（12组匹配+4家店铺）
│   │   └── main.js     # 交互逻辑（粒子背景+动画+匹配+仪表盘）
│   └── img/            # 图片目录（预留）
└── README.md
```

## 功能亮点

### 首页
- 粒子连线背景动画
- Hero 大标题渐变文字 + 旋转光环
- 4个数据统计卡片（数字滚动动画）
- 6个功能介绍卡片
- 3个商业模式卡片
- 滚动渐入动画

### 匹配演示（学生端）
- 12组预置需求示例
- 输入需求 → 4步loading动画（提取关键词→标签分类→二分图匹配→排序推送）
- 3个匹配结果卡片，依次淡入
- 环形匹配度进度条
- 需求关键词标签展示

### 商家端
- 4家店铺切换（教材店/奶茶店/车行/打印店）
- 4个统计指标
- 本周需求趋势柱状图
- 需求热度排行（带进度条动画）
- 智能进货建议

### 关于
- 双人团队卡片（悬停光晕效果）
- 6阶段发展时间线

## 设计规范

- 配色：深黑底 #08080C + 古铜金 #B8860B/#D4A84B + 米白字 #F2EBDF
- 字体：系统默认无衬线
- 响应式：适配手机/平板/电脑
- 无外部依赖，纯 HTML/CSS/JS

## 部署到 GitHub Pages

1. GitHub 新建仓库
2. 上传所有文件到仓库根目录
3. Settings → Pages → Source 选 `Deploy from a branch` → `main` / `(root)`
4. 访问 `https://用户名.github.io/仓库名/`
